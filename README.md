# Mrzdevcore Tap

## How do I install these formulae?

`brew install mrzdevcore/tap/<formula>`

Or `brew tap mrzdevcore/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mrzdevcore/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
